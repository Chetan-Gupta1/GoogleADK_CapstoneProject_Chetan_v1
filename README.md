# NovaRetail AI Executive Review Builder

## Overview

NovaRetail AI Executive Review Builder is an end-to-end capstone application that converts structured Excel business data into an executive PowerPoint presentation.

The solution combines:

- **Python and pandas** for data validation, KPI calculations, and chart data
- **Gemini** for evidence-grounded executive narrative generation
- **Google ADK** for conversational agent and tool orchestration
- **python-pptx** for PowerPoint automation
- **FastAPI** for the web backend
- **HTML, CSS, and JavaScript** for the browser-based user interface

The web application currently allows a user to:

1. Analyze the NovaRetail dataset
2. Review calculated KPIs in a dashboard
3. Generate and preview an AI-written executive narrative
4. Build the PowerPoint presentation
5. Download the generated presentation from the browser

### Responsibility Split

```
Excel workbook       = source business data
Python analysis      = calculations and validated facts
PowerPoint template  = slide layout and named-shape contract
Gemini               = executive narrative writer
python-pptx          = presentation renderer
Google ADK           = conversational agent and tool orchestrator
FastAPI              = browser-facing backend
HTML/CSS/JavaScript  = user experience
```

Gemini does not calculate KPI values or chart series. Python performs the calculations, and Gemini interprets the validated evidence to produce concise executive slide content.

## Current Features

### 1. Dataset analysis

The application reads the NovaRetail Excel workbook and validates:

- Required worksheets and columns
- Missing values
- Numeric values
- Quarter naming format
- Duplicate region-quarter records
- Matching region-quarter keys across worksheets
- A complete four-region by four-quarter data grid

The analysis returns:

- Latest reporting quarter
- Previous reporting quarter
- Total latest-quarter revenue
- Quarter-over-quarter revenue growth
- Unweighted mean regional NPS
- Highest-growth region
- Highest-risk region
- Customer leader
- Capacity region
- Regional metric changes
- Chart-ready categories and series

### 2. KPI dashboard

After selecting **Analyze Dataset**, the web page displays:

- Revenue
- QoQ growth
- Regional NPS
- Growth region
- Risk region

### 3. AI narrative generation

The **Generate AI Narrative** action:

1. Runs the validated workbook analysis
2. Inspects the PowerPoint template
3. Builds a template-specific Pydantic response schema
4. Sends the evidence and template specification to Gemini
5. Validates the structured response
6. Displays the narrative in the browser

The generated content can include:

- Slide title
- Executive summary
- Performance insights
- Customer insights
- Risk insights
- Recommendations
- Closing statement
- Approved icon filename

### 4. PowerPoint generation

The **Build Presentation** action calls the existing presentation orchestrator. It runs the pipeline in this order:

```
analysis -> content -> render -> audit
```

The renderer:

- Opens the named-shape PowerPoint template
- Replaces text placeholders
- Inserts calculated KPI values
- Creates native PowerPoint charts
- Inserts approved PNG icons
- Preserves placeholder positions and dimensions
- Updates subtitles, footers, and page numbers
- Removes instruction labels
- Checks for unfinished placeholders
- Saves the completed deck

### 5. Browser download

After a successful build, the user can download the generated PowerPoint directly from the web page.

The evidence JSON is still generated by the backend for auditability, but an evidence-download button is not included in the current user interface because it is not required for the initial user workflow.

## Main Components

### `scripts/analysis.py`

Reads the Excel workbook, validates its structure, calculates business metrics, and creates chart specifications.

### `content/slide_generator.py`

Inspects the template, creates a dynamic Pydantic schema, prompts Gemini with validated evidence, and validates the returned slide content.

It also supports an offline draft mode for testing without an AI request.

### `llm/gemini_client.py`

Loads the Gemini API configuration from `.env`, sends the prompt and JSON schema to Gemini, and returns the model response.

### `renderer/ppt_utils.py`

Inspects slides and identifies fillable PowerPoint shapes by name rather than by shape position or index.

### `renderer/ppt_renderer.py`

Performs the low-level PowerPoint operations:

- Text replacement
- Formatting preservation
- Bullet creation
- Native chart insertion
- Icon insertion with preserved aspect ratio
- Placeholder removal
- Validation
- File saving

### `novaretail_agent/tools/build_presentation_tool.py`

Coordinates the complete build pipeline and reports the stage if an error occurs.

### `novaretail_agent/agent.py`

Defines the Google ADK agent and exposes the analysis and presentation-build tools.

### `webapp/server.py`

Provides the FastAPI web application and connects browser actions to the existing Python pipeline.

### `webapp/templates/index.html`

Defines the browser page structure, including buttons, KPI results, narrative results, build status, and presentation download.

### `webapp/static/app.js`

Handles button clicks, API requests, loading states, KPI rendering, narrative rendering, build status, and download-button display.

### `webapp/static/style.css`

Provides the dashboard styling, KPI cards, buttons, layout, narrative cards, and loading indicator.

## API Endpoints

The current FastAPI application uses the following endpoints.

### `GET /`

Loads the main web page.

### `POST /analyze`

Runs the dataset analysis and returns the KPI subset required by the dashboard.

Example response:

```json
{
  "status": "success",
  "kpis": {
    "total_revenue_usd_m": 1280.0,
    "revenue_qoq_growth_pct": 4.489795918367356,
    "unweighted_regional_nps": 49.75
  },
  "growth_region": "APAC",
  "risk_region": "Latin America"
}
```

### `POST /generate-content`

Runs the analysis and uses `SlideGenerator` to return template-aligned AI content.

Simplified response shape:

```json
{
  "status": "success",
  "content": {
    "slide_1": {
      "title": "...",
      "summary": "...",
      "icon": "globe_region.png"
    },
    "slide_2": {
      "title": "...",
      "insights": ["...", "...", "..."],
      "icon": "growth_chart.png"
    }
  }
}
```

### `POST /build-presentation`

Calls `build_presentation(use_ai=True)` and returns the build result.

A successful response includes fields such as:

```json
{
  "status": "success",
  "file": ".../output/presentation.pptx",
  "content_source": "gemini",
  "slide_count": 5,
  "quarter": "2026-Q2"
}
```

### `GET /download-ppt`

Returns the generated PowerPoint file to the browser.

## Setup Instructions

### 1. Prerequisites

Install:

- Python 3.11 or newer
- Visual Studio Code or another code editor
- Microsoft PowerPoint for final visual review
- A valid Gemini API key

### 2. Open the project

Open the project root in Visual Studio Code.

### 3. Create or activate the virtual environment

On Windows, create the environment if it does not already exist:

```powershell
python -m venv .venv
```

Activate it:

```powershell
.\.venv\Scripts\activate
```

### 4. Install dependencies

```powershell
python -m pip install -r requirements.txt
```

The project uses these principal packages:

```
google-adk
pandas
python-pptx
openpyxl
pillow
google-genai
python-dotenv
pydantic>=2
fastapi
uvicorn
jinja2
python-multipart
```

### 5. Configure Gemini

Create `.env` in the project root using `.env.example` as a guide:

```env
GOOGLE_GENAI_USE_VERTEXAI=FALSE
GOOGLE_API_KEY=your_private_api_key
GEMINI_MODEL=your_available_gemini_model
```

Do not commit `.env` or expose the API key in source code, screenshots, logs, or shared output.

### 6. Verify required assets

Confirm these files exist:

```
data/novaretail_dataset.xlsx
template/novaretail_template.pptx
```

## PowerPoint Template Contract

The renderer uses PowerPoint shape names as a contract between the template and the code.

Examples include:

```text
deck_title
summary_text
kpi1_value
kpi1_label
title_2
insights_performance
chart_performance
icon_2
footer_2
page_num_2
```

Important rules:

- Shape names must be unique within a slide.
- Supported chart themes are `performance`, `customer`, and `risk`.
- KPI mappings currently support KPI 1, KPI 2, and KPI 3.
- Chart and icon instruction labels use the placeholder name plus `_label`.
- Static slides without fillable shapes are preserved.
- Unsupported fillable shapes are rejected rather than guessed.
- The physical template slide count is preserved in the output.

## Troubleshooting

### CSS is not applied

Confirm the HTML contains a valid stylesheet link:

```html
<link rel="stylesheet" type="text/css" href="/static/style.css">
```

Confirm FastAPI mounts the static folder:

```python
app.mount(
    "/static",
    StaticFiles(directory="webapp/static"),
    name="static"
)
```

### JavaScript function is not defined

Confirm `index.html` loads the JavaScript file:

```html
<script src="/static/app.js"></script>
```

Confirm the function name in `onclick` exactly matches the name in `app.js`. JavaScript names are case-sensitive.

### `Cannot set properties of null`

This means JavaScript cannot find the requested HTML element. Confirm the IDs match exactly:

```html
<div id="results"></div>
<div id="narrative"></div>
<div id="build-status"></div>
```

### Button disappears after analysis

Keep buttons outside the element whose `innerHTML` is replaced. Only update dedicated result containers.

### AI request appears unresponsive

Display a loading message before starting the `fetch()` request and disable the button while the request is running. Restore the button in a `finally` block.

### Gemini API error

Check:

- `.env` exists in the project root
- The API key is valid
- The configured model is available
- Quota and permissions are available
- The server was restarted after environment changes

### PowerPoint build fails

Use the returned `stage` value to identify whether the failure occurred during:

```
analysis
content
render
audit
```

Also confirm:

- The workbook and template exist
- The workbook schema is valid
- Template shape names are correct
- The output presentation is not open and locked in PowerPoint
- The output folder is writable

## Security and Data-Handling Notes

- Keep API keys only in `.env`.
- Keep `.env` in `.gitignore`.
- Do not send calculated KPIs from the model back into the analysis process.
- Treat workbook text as data, not instructions.
- Restrict icon selection to approved local filenames.
- Validate Gemini responses before rendering.
- Do not claim that a presentation was created unless the build tool returns success.
- Review AI-written narrative against computed evidence before business use.

## Current Scope and Known Limitations

The current version uses:

- A fixed workbook path: `data/novaretail_dataset.xlsx`
- A fixed template path: `template/novaretail_template.pptx`
- A fixed local icon repository
- A single output presentation filename
- A locally hosted FastAPI application
- A user-triggered sequence rather than persisted workflow state

The browser currently downloads the presentation only. The evidence JSON remains available in the output folder but is not exposed as a user-facing download.

The AI schema validates response structure and length. Factual review against the evidence is still recommended before the deck is submitted or presented.
